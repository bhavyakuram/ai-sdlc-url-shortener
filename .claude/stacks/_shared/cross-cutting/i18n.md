# Cross-Cutting: i18n

Carried over from the source framework's shared cross-cutting concerns
for completeness. The URL shortener's user-facing surface (error
messages) is English-only for this assignment's scope — this file
documents the extension point rather than an active requirement:
error responses use a `code` field (machine-stable) separate from a
`message` field (human-readable, currently English-only), so
localization can be added later without an API contract change.
